# Database Technology Choice

## Status
`Superseded`
*Superseded by [ADR-0006: Database Technology Choice](./0006-db.md)*

## Context
When we began the project, our main priority was implementing the Nightscout API and creating our own documentation, since the official Nightscout docs were incomplete. Choosing a database was less of a concern at the time; we needed something that would work out of the box so we could focus on development and documentation.

## Decision
We chose **MySQL** as our database because it comes bundled with Laravel Sail, making the setup process fast and effortless. MySQL is also a well-known and widely supported database system, so we knew it would work reliably in most environments and wouldn’t slow us down during the early stages of the project.

## Consequences
- Database setup was quick and did not distract from higher-priority tasks like API development and documentation.
- Using Sail’s defaults reduced initial configuration and compatibility issues.
- MySQL’s wide support made it easy to run locally and on most hosts.
- We did not spend time evaluating other database options in depth at this stage.

## Alternatives Considered
- **PostgreSQL, SQLite, or other databases:** Not evaluated in detail, since MySQL was the default with Sail and met our immediate needs for development.
